# Earth Speed Calculator (Physics & AddMath Model) (With the help of some Artificial Intelligence)

This repository contains a Python script that calculates the translational (orbital) and rotational speeds of the Earth using standard kinematics and orbital mechanics formulas. 

I built this project to practice applying **Advanced Mathematics (AddMath)** and physics concepts directly into Python code.

## Key Features Covered
* **Orbital Velocity:** Calculated using Newton's Law of Universal Gravitation and Centripetal Force.
* **Rotational Speed:** Uses trigonometry to adjust linear velocity based on latitude coordinates.
* **Vector Components:** Resolves orbital speed into $x$ and $y$ velocity vectors over time.

## How to Run
1. Clone this repository or download the script.
2. Run the script using Python:
   ```bash
   python earth_speed.py
   ```
